Arsip PO

Kalau satu periode PO/gelombang sudah ditutup, pesanan-pesanannya bisa dibackup ke file lalu dihapus dari database supaya hemat ruang. File backup bisa dipulihkan (restore) lagi kapan pun kalau datanya ingin ditampilkan ulang.

Buat Backup Baru

Tentukan pesanan mana yang mau diarsipkan. Dari Tanggal & Sampai Tanggal wajib diisi (supaya tidak tidak sengaja membackup seluruh riwayat pesanan sekaligus).

Riwayat Arsip

Restore dari File Backup

Pilih file backup (.json) yang pernah diunduh dari halaman ini untuk menampilkan lagi pesanan-pesanan di dalamnya.

Restore dari File Backup

Restore data (menulis ulang pesanan lama ke database) khusus Owner -- ini setara mengimpor data mentah, jadi sengaja dibatasi lebih ketat daripada Backup. Silakan minta Owner membuka halaman ini kalau perlu me-restore file backup.
