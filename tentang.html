Toko Sumber Jaya

Sistem Manajemen Pesanan Preorder Benih

Versi 1.3

Tujuan Aplikasi

Mencatat pesanan preorder benih dari pembeli, memantau status bayar & ambil, sampai laporan penjualan — untuk 1 toko dengan beberapa cabang, dikelola langsung dari browser tanpa perlu instalasi khusus.

Dipakai Oleh

Owner, Admin Kasir, dan Karyawan tiap cabang — masing-masing dengan hak akses berbeda. Lihat halaman Panduan untuk detail cara pakai tiap peran.

Dibangun Dengan

HTML/JavaScript statis + Firebase (Firestore, Authentication, Realtime Database) — di-hosting gratis selamanya lewat GitHub Pages, tanpa server/biaya bulanan.

HTML/CSS/JS Firebase GitHub Pages Chart.js PWA

Fitur Utama

Kemampuan inti aplikasi ini sejak awal dibangun. Perubahan/penambahan sesudahnya ada di Riwayat Pembaruan di bawah.

Manajemen Pesanan

  • Input pesanan multi-produk & multi-gelombang harga sekaligus
  • Uang muka & pelunasan bertahap, status bayar otomatis
  • Nomor nota otomatis, tidak pernah bentrok
  • Tandai status "sudah diambil" per pesanan
  • Filter & pencarian: tanggal, cabang, produk, gelombang, status
  • Deteksi otomatis pesanan dengan harga janggal
  • Riwayat/log tiap kali pesanan diedit

Multi-Cabang & Multi-Peran

  • Kelola banyak cabang dalam 1 aplikasi
  • 3 peran akun: Owner, Admin Kasir, Karyawan cabang
  • Karyawan cabang hanya melihat data cabangnya sendiri
  • Kelola akun staf & status aktif/nonaktif
  • Status online staf secara real-time

Laporan & Analitik

  • Dashboard ringkasan penjualan & grafik tren
  • Laporan lengkap dengan filter, siap export
  • Export ke Excel (.xlsx) dan PDF
  • Cetak nota format A4 maupun struk kecil (dot-matrix)

Produk & Stok

  • Kelola produk & gelombang harga per periode
  • Kuota per gelombang, otomatis dihitung terpakai
  • Catatan stok (bukan pengurangan stok otomatis)

Komunikasi Pembeli

  • Kirim pesan WhatsApp "siap diambil" 1 klik
  • Kirim pesan pengingat tagihan belum lunas
  • Kirim WA massal ke banyak pembeli sekaligus

Keamanan & Data

  • Login per akun, 1 sesi aktif per perangkat
  • Backup, restore, dan hapus arsip data lama
  • Aturan akses data ketat per peran (Firestore Rules)
  • Ganti password mandiri per akun

Kenyamanan Pemakaian

  • Bisa dipasang seperti aplikasi (PWA) di HP/laptop
  • Mode gelap & terang, otomatis ikut sistem
  • Tampilan responsif — nyaman dipakai di HP maupun komputer
  • Pencarian cepat lintas halaman
